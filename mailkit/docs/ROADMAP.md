# 路线图 — 把整条达人营销工作流做成一个自动化项目

定位:mailkit 不是孤立收发工具,是 `rockbase-skills` 工作流的 **S2/S3 收发自动化层**。
全项目终点 = 每个阶段服务化 + 阶段间数据自动流转,人工只做业务决策(选谁、报什么价)。

## 工作流地图(rockbase-skills v2.0.0)

```
S1 发现/补全 → S2 草稿/外联 → S3 回复运营 → S4 活跃资产 → S5 匹配、QC 与同步
   ↑ 社媒模糊发现       ↑ 批量草稿       ↑ 回复归因      ↑ 活跃补全    ↑ brief 匹配/OCR 同步/
   ↑ inbox enrichment   ↑ (mailkit send)  ↑ (mailkit       ↑            查重/发票/视觉汇报
                                          receiver+sync)
```

## 当前人工干预点清单(自动化欠账)

| # | 干预点 | 现状 | 目标 |
|---|--------|------|------|
| 1 | S2 真发触发 | 人工导出 CSV → 手跑 `mailkit.send --execute` | wave 队列服务化:worker 定时取队列自动发(对接 S3 queue) |
| 2 | 收件 | Gmail 手工盯 | **mailkit 上公司服务器,postfix pipe 接真流量**(第一优先) |
| 3 | 回复归因 | 已自动化(master_sync) | 保持;加定时调度自动跑 |
| 4 | S2 草稿生成 | skill 生成 → 人工导出 | 草稿 skill 直连 send.py 计划接口,守卫统一 |
| 5 | S5 表格同步/查重/发票 | 脚本,人工跑 | 挂定时任务 + 变更触发 |
| 6 | 阶段间流转 | 人拷表格 | 统一 master 表为唯一事实源,各阶段读写它 |

## 阶段计划

- **P0(当前)** mailkit 部署上服务器:postfix pipe + receiver 常驻 + 定时 master_sync。验收 = 真实进站邮件自动落库自动回填,零人工。
- **P1** S2 发送服务化:wave 队列(worker)替代手动 `--execute`,dry-run 预览保留为守卫闸。
- **P2** 阶段间自动流转:master 表事件驱动(S3 收到 replied → 通知草稿层拟 mail2)。
- **P3** S1/S5 调度化:社媒发现定时跑、表格同步/查重/发票变更触发。
- **贯穿** 每步先 dry-run/模板验证,守卫纪律(首触无外链/节奏上限/不猜字段)永不下放给自动化。

原则:🚫 为自动化砍守卫;自动化替代的是誊抄和等待,不是业务判断。
