# Validation Scenarios

- TikTok `content-first` keyword search returns creator-level evidence rows.
- TikTok `account-first` yields enough profile fields for L2.
- Blocked paths return structured operator requirements instead of empty output.
- Shared downstream L2/L3/S2 contract remains compatible.
- L3 should downgrade obvious org/media accounts instead of letting them pass on score alone.
- L3 should flag `big / huge` accounts for creator-fit review before S2.
- Discovery master should allow same-batch reruns and same-project re-seen rows, while only hard-blocking suppressed rows.
