## Core Principles

1. 只有已拿到 usable quote，才进入这份 reference。
2. 压价动作必须建立在完整 thread 上，而不是看到一个数字就机械套模板。
3. 压价的重点不只是降总价，也包括拆 starter option、拆 single unit、调整 usage 和 bundle。
4. 如果最新 pointer 显示当前 thread 仍停在价格补齐阶段，就必须退回 `WF-1`。

## Main Scenarios

### N1. First Quote Too High

动作：

- 用 first-test framing 压价
- 问是否有 lighter entry point

### N2. Bundle Too Large

动作：

- 不直接拒绝
- 追问 smaller scope

### N3. Usage Makes Price Too Heavy

动作：

- 问无 usage 版本
- 或拆 usage separately

### N4. Quote Usable But Needs Recut

动作：

- 把大方案改成更适合 starter test 的结构

## Negotiation Moves

### Move A. First-Test Framing

强调：

- initial test
- first collaboration
- smaller starting point

### Move B. Starter Option

强调：

- simpler entry point
- single format
- lighter first round

### Move C. Scope Recut

强调：

- remove paid usage
- reduce bundle
- keep only the most relevant format

## Self-Check

正文完成后必须确认：

- 我们是不是已经拿到 usable quote
- 这封的主目标是不是谈价，而不是补价格信息
- 有没有把 bundle / usage / starter option 的推进点说清楚
- 有没有错误地回成“只是记录一下价格”
