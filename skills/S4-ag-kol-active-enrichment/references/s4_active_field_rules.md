# S4 Active Field Rules

## 目标

把 `S1` 平台原始字段转成 `S4 Active KOL Library` 可复用字段。

当前优先字段：

1. `账号类目标签`
2. `账号简介`

## 输入优先级

1. `账号简介__平台抓取`
2. `账号类目标签__平台抓取`
3. `外链__平台抓取`
4. `粉丝受众 / 粉丝性别 / 粉丝年龄`
5. `联系方式`

## 推荐输出

### 0. `账号类目标签`

- 必须按 `tag-system/account_category_label_standard.md` 受控词表填写
- 用于 Rockbase 内部快速筛选，不保留平台噪音词
- 默认写成 `一级类目` 或 `一级类目/二级方向`

### 0. `账号简介`

- 必须按 `account_bio_rewrite_standard.md` 规则填写
- 写成一句中文内部简介
- 重点承载定位、内容方向、合作适配
- 默认先产出可用草稿，再对知名账号做高价值润色
- 如果脚本结果虽然正确但明显模板化，必须允许人工或模型二次校正

### 1. 内部定位简述

- 一句中文
- 重点写内容主题、表达方式、适合合作方向
- 用于团队快速判断，不追求修辞

### 2. 客户友好标签

- 把平台原始标签压成 2-5 个可读标签
- 优先客户易懂，不保留平台噪音词

### 3. 合作方向

- 描述适合什么类型产品或合作方向
- 不能超出原始素材支持范围

### 4. 当前关系状态

- 如 `replied`、`active`、`negotiating`、`closed`
- 来自运营状态，不来自平台抓取

## 禁止事项

- 不凭空补经历、价格、合作历史
- 不在素材不足时写满整段客户文案
- 不把 `S4` 误当成 `S5` 报告生成器
- 不把 `账号类目标签__平台抓取` 直接复制到 `账号类目标签`
- 不把 `账号简介__平台抓取` 直接复制到 `账号简介`
